# Tip Calculator

## About
A simple Python program that calculates how much to leave as a tip based on the meal cost and the chosen tip percentage. It converts dollar amounts and percentages from strings into floating-point numbers.

## How It Works
- Asks the user for the meal cost.
- Asks what percentage they would like to tip.
- Removes the `$` and `%` symbols and converts the values to floats.
- Calculates and displays the tip amount rounded to two decimal places.

## Example
```text
How much was the meal? $50.00
What percentage would you like to tip? 15%
Leave $7.50
```
